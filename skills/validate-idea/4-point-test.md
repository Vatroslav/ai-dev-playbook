# 4-point test (validate before building)

Order: sniff test -> hypothesis -> riskiest assumptions -> minimum criteria for success. The point is to spend minutes, not weeks, finding out an idea is weak.

Sources: compiled from several product-management courses and books on idea and assumption testing; the combination and wording are this playbook's own.

## 1. Sniff test

No research; instinct. It filters before you spend effort.
- **Pain vs payment:** how much does the problem hurt, and does anyone pay (money, time, attention) to solve it today?
- **Team fit:** do we have the skills, experience or access this needs?
- **Sustainability:** would we still want to work on this in a year?
- **Path to validation:** can we name the first three steps to test it right now?
- **Unfair advantages:** what do we have that others don't (access to users, data, a skill, a community)?

## 2. Hypothesis

One written, testable claim. Pick the template that fits:
- Simple: "We believe <target user> will <action> because <reason>."
- Change: "If we <action>, we believe <target user> will <outcome> because <reason>."
- Product: "We believe <target user> has <problem> because <reason>. If we <action>, <metric> will improve."

## 3. Riskiest assumptions

"For this to work, the following must be true..." In the usual order of risk:
1. They have the problem (riskiest).
2. They care enough to change what they do.
3. They will pay, or another monetization works.
4. There is no satisfactory substitute or workaround they already use.

Place each assumption on risk x difficulty to test:

| | Easy to test | Hard to test |
|---|---|---|
| **High risk** | Test first | Test second |
| **Low risk** | Test third | Ignore for now |

## 4. Minimum criteria for success

- **Costs:** hours, money, and the opportunity cost (what we won't build meanwhile).
- **Reward:** ONE metric with a threshold and a time window - signups in a period, conversion, retention, revenue, or lifetime value above acquisition cost.
- Decide the threshold before the test, and what happens if it is missed.
